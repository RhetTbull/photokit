#### [v0.3.0](https://github.com/RhetTbull/photokit/compare/v0.2.1...v0.3.0)

> 27 September 2026

- Added `PhotoAsset.edit()` to edit photos and videos with a callback, including Live Photos with an edited paired video, and `PhotoAsset.revert()` to revert to the original [`#6`](https://github.com/RhetTbull/photokit/pull/6)
- Added `PhotoLibrary.add_photo_with_adjustments()`, `add_video_with_adjustments()`, `add_live_photo_with_adjustments()`, and `add_raw_pair_photo_with_adjustments()` to add an original with an edited version and adjustment data from an AAE file [`#6`](https://github.com/RhetTbull/photokit/pull/6)
- Added example scripts for editing photos and videos with Core Image filters [`#6`](https://github.com/RhetTbull/photokit/pull/6)
- Fixed errors from PhotoKit change requests not always being raised as `PhotoKitChangeError` [`#6`](https://github.com/RhetTbull/photokit/pull/6)
- Bound PhotoKit image, resource, and video requests with a timeout (`PHOTOKIT_REQUEST_TIMEOUT`, raises `PhotoKitTimeoutError`) to fix an indefinite hang when an iCloud download stalls [`#5`](https://github.com/RhetTbull/photokit/pull/5)
- Fixed `PhotoLibrary.albums()` on macOS 27; `albums()` now returns only regular user albums, excluding shared albums and projects [`#7`](https://github.com/RhetTbull/photokit/pull/7)
- Fixed `PhotoLibrary.assets()` in multi-library mode returning photos received in Messages that are not shown in the library [`#7`](https://github.com/RhetTbull/photokit/pull/7)
- Removed `PhotoLibrary.create_library()` as the private API it used no longer works [`489ff1f`](https://github.com/RhetTbull/photokit/commit/489ff1f347d0d70338c13a572abd37af78fa61a3)
